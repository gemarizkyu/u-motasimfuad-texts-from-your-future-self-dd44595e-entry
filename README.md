A tiny deterministic Python program that writes one funny text message from your future self to `entry.txt`.

## The text

> "Future you here. Stop buying plants. They keep dying, and the neighbours now think you run a tiny funeral home for succulents. Even the cactus gave up."

151 characters — comfortably under the 200-character cap — written verbatim to `entry.txt`.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Deterministic

Same fixed string every run. No randomness, no network, no clock — the output is identical each time.
